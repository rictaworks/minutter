# 仕様書

プロジェクト名: minutter
エディション: デモ版
プラットフォーム: デスクトップ（Rust + Tauri + React/TypeScript）

---

## 1. プロジェクト概要

| 項目 | 内容 |
|------|------|
| プロジェクト名 | minutter |
| エディション | デモ版（体験版） |
| プラットフォーム | デスクトップ |
| 認証 | なし（ローカルアプリのため不要） |
| DB | SQLite（デモ版固定・シングルユーザー） |
| 外部API | 一切使用不可 |
| 配布形式 | インストーラー（.msi / .dmg / .deb） |
| 実装方式 | 1issueのワンショット実装 |

---

## 2. プラットフォーム選定根拠

| 観点 | 理由 |
|------|------|
| 技術的必然性 | Voskモデルが約500MB → クラウドへのデプロイに根本的に不向き |
| 技術的必然性 | 音声認識がオフライン完結 → サーバーに置く意味がない |
| 技術的必然性 | マイク録音がローカル前提 → クラウド経由にするとレイテンシ・権限問題が発生 |
| UX | 会議の録音・議事録はプライバシーが高い → ローカル完結の方が安心感がある |
| UX | ネット環境に依存しない → 会議室・移動中でも使える |
| 設計のシンプルさ | シングルユーザーなのでセッション管理・認証が不要 |
| 設計のシンプルさ | 自動リセット・メンテナンスモード・Honeypotなどの不要な複雑さを排除できる |

---

## 3. 技術スタック

| レイヤー | 技術 |
|---------|------|
| フレームワーク | Tauri v2（Rust + React/TypeScript） |
| バックエンドロジック | Rust |
| UI | React（TypeScript）+ Tailwind CSS |
| 音声キャプチャ | cpal（Rustクレート） |
| 音声変換 | ffmpeg-next（Rustバインディング）+ Tauriサイドカー |
| 音声認識 | Vosk-API Rust バインディング（日本語モデル同梱） |
| テキスト処理 | ルールベース（Rustで実装） |
| DB | SQLite（rusqlite） |
| DBパス | OS標準のAppDataディレクトリ |

---

## 4. DBファイル配置パス

| OS | パス |
|----|------|
| Windows | `%APPDATA%\minutter\data.db` |
| macOS | `~/Library/Application Support/minutter/data.db` |
| Linux | `~/.local/share/minutter/data.db` |

---

## 5. 機能一覧

| 機能ID | 機能名 | 概要 |
|--------|--------|------|
| F01 | マイク録音 | cpalでPCMキャプチャ → WAV保存（上限100MB） |
| F02 | ファイルインポート | WAV/MP3/M4A/WebMをインポート（非WAVはffmpegでWAV変換） |
| F03 | 文字起こし | VoskによるオフラインSTT（日本語）、手動編集可 |
| F04 | 議事録生成 | ルールベースで決定事項・次回議題・本文を構造化 |
| F05 | ToDo抽出 | ルールベースでToDo候補を抽出・期限自動検出、チェック選択・手動追記 |
| F06 | 要約生成 | TextRank簡易版で全体の15〜20%に圧縮 |
| F07 | 会議一覧 | 過去の会議記録を一覧表示・手動削除 |
| F08 | 手動再生成 | テキスト編集後に議事録・ToDo・要約を再生成 |

---

## 6. 非機能要件

| 項目 | 要件 |
|------|------|
| ファイルサイズ上限 | 100MB（超過時は自動停止・警告） |
| 文字起こし精度 | Vosk日本語モデルで明瞭音声90%以上 |
| 対応OS | Windows 10/11 / macOS 13以降 / Ubuntu 22.04 |
| 配布形式 | .msi（Windows）/ .dmg（macOS）/ .deb（Linux） |
| SQLインジェクション対策 | rusqliteのプリペアドステートメント必須 |
| 個人情報 | 一切収集しない（ローカル保存のみ） |

---

## 7. 個人情報非収集方針

| 禁止データ | 本システムでの対応 |
|-----------|-----------------|
| 生年月日 | 収集しない |
| 氏名・ニックネーム | 収集しない（ローカルアプリ・認証なし） |
| メールアドレス | 収集しない |
| 住所・電話番号 | 収集しない |

---

## 8. デモ版固有の制約事項

- ユーザー認証・認可なし（ローカルアプリのため不要）
- 外部API（ネットワーク越しの呼び出し・APIキーが必要なもの）使用禁止
- DBはSQLite固定（シングルユーザー）
- セッション管理・自動リセット・メンテナンスモード・Honeypotは不要のため実装しない
- Voskモデル未配置時はエラー表示・ダウンロードURL案内（アプリ内自動ダウンロード禁止）

---

## 9. AI機能の代替方針（デモ版）

外部API禁止のため、以下のルールベース処理で代替する。

| AI機能（MVP以降） | デモ版での代替 |
|-----------------|--------------|
| AI文字起こし（Whisper API等） | Vosk（オフライン・同梱）によるローカルSTT |
| AI議事録生成（LLM） | キーワードマッチによるルールベース構造化 |
| AI要約（LLM） | TextRank簡易版（文スコアリングによる抽出型要約） |
| AI ToDo抽出（LLM） | キーワードマッチ＋過去文・否定文フィルタ |

MVP以降はWhisper.cpp（ローカルLLM）への移行を想定する。
