# クラス図（Rustモジュール構成）

```mermaid
classDiagram
    class AudioRecorder {
        -device: cpal::Device
        -stream: Option~Stream~
        -output_path: PathBuf
        -max_bytes: u64
        +start() Result
        +stop() Result~PathBuf~
        +list_devices() Vec
        +select_device(id)
    }

    class AudioImporter {
        -ffmpeg_path: PathBuf
        +import(path) Result~PathBuf~
        -convert_to_wav(path)
        -validate_format(path) bool
    }

    class VoskTranscriber {
        -model: vosk::Model
        -model_path: PathBuf
        +check_model() bool
        +transcribe(wav) Result~TranscriptResult~
    }

    class TextProcessor {
        -keywords_decision: Vec
        -keywords_todo: Vec
        -keywords_next: Vec
        -keywords_past: Vec
        -keywords_negation: Vec
        +generate_minutes(text) Vec~Minute~
        +extract_todos(text) Vec~Todo~
        +summarize(text) String
        -split_sentences(text) Vec~String~
        -score_sentences(sents) Vec~f64~
        -filter_past(sents) Vec~String~
        -filter_negation(sents) Vec~String~
        -deduplicate(items) Vec~String~
    }

    class MeetingRepository {
        -conn: Connection
        +init_db() Result
        +check_integrity() bool
        +save_meeting(m) Result~Uuid~
        +save_transcript(t) Result
        +save_minutes(items) Result
        +save_todos(items) Result
        +save_summary(s) Result
        +list_meetings() Vec~Meeting~
        +delete_meeting(id) Result
    }

    class MeetingStatus {
        <<enumeration>>
        Recording
        Processing
        Done
        Error
    }

    AudioRecorder --> VoskTranscriber : produces WAV
    AudioImporter --> VoskTranscriber : produces WAV
    VoskTranscriber --> TextProcessor : raw_text
    TextProcessor --> MeetingRepository : Minute / Todo / Summary
    MeetingRepository --> MeetingStatus : uses
```

## 補足

- `AudioImporter` は Tauri サイドカーとして ffmpeg を呼び出す
- `VoskTranscriber` は日本語モデル（約500MB）をバンドルする
- `TextProcessor` はルールベース処理のみ（外部 API・LLM 不使用）
- `MeetingRepository` は rusqlite のプリペアドステートメントを必須とする
