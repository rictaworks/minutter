# テスト制約・注意事項

## デモ版でテストできることの限界

デモ版はシングルユーザー・ローカル完結のアプリであるため、以下の制約がテスト時に適用される。

| 制約項目 | 詳細 |
|---------|------|
| シングルユーザーのみ | マルチユーザー・チーム共有のテストは不可。MVP以降で対応 |
| Voskの精度上限 | オフラインSTTのため、複数人・ノイズ環境での認識精度に限界がある。MVP以降でWhisper.cpp等に移行予定 |
| ルールベースの限界 | LLMを使用しないため、議事録・ToDo・要約の品質はキーワード依存度が高い。抽象的・暗黙的な発言は処理できない |
| マスタデータなし | 本システムにマスタデータは存在しない。テスト可能な最小単位は「1会議分の録音データ」 |
| クロスプラットフォーム差異 | cpal・ffmpeg・VoskのOS別動作差異はCI/CDで検証が必要（特にLinux環境） |

---

## MVP以降で解消される制約

| デモ版の制約 | MVP以降の対応 |
|------------|-------------|
| Voskの精度 | Whisper.cpp（ローカル）または Whisper API に移行 |
| ルールベース処理 | ローカルLLM（ollama等）または外部LLM APIによる高精度処理 |
| シングルユーザー | クラウド同期・チーム共有機能の追加 |
| ローカルのみ | バックアップ・エクスポート機能の追加 |

---

## Voskモデルのセットアップ要件

デモ版を動作させるには、以下を事前に配置する必要がある。

```
# Voskモデルのダウンロード（日本語）
# vosk-model-ja-0.22（約500MB）を以下に配置
# Windows: %APPDATA%\minutter\models\vosk-model-ja\
# macOS:   ~/Library/Application Support/minutter/models/vosk-model-ja/
# Linux:   ~/.local/share/minutter/models/vosk-model-ja/
```

Voskモデルが未配置の場合：
- アプリは起動時に検出し、エラー画面を表示する
- フォールバック（文字起こしなし）は行わない
- ダウンロードURLをエラー画面に表示する
- アプリ内での自動ダウンロードは実装しない
